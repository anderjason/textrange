# Security Policy

## Supported Versions

Before a stable release, only the latest code on `main` is supported.

## Reporting A Vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting from the repository's **Security** tab: open **Advisories**, then choose **Report a vulnerability**. Include the affected code or version, steps to reproduce the issue, its likely impact, and any suggested mitigation.
